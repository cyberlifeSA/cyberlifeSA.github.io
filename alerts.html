Jan, 22, 2025, 02:37 AM SOC335 Exploitation Detected (CVE-2024-49138) Medium TP T1190T1059
Details
Durante el analisis del endpoint Victor (172.16.17.207), se identifico una cadena de ejecucion iniciada mediante PowerShell el 22-Jan-2025 a las 14:36. El proceso realizo consultas mediante whoami.exe y whoami.exe /priv, indicando actividades de descubrimiento del usuario y privilegios disponibles. Posteriormente, PowerShell ejecuto una descarga desde https://files-ld.s3.us-east-2.amazonaws.com/service-installer.zip, la cual coincide con la ruta donde fue identificado el ejecutable sospechoso C:\temp\service_installer\svohost.exe. El archivo svohost.exe presenta multiples indicadores sospechosos, incluyendo similitud con procesos legitimos de Windows, ejecucion desde una ubicacion no estandar y detecciones YARA asociadas a herramientas maliciosas. La actividad observada es consistente con transferencia y ejecucion de un posible payload malicioso. Se escala a L2 Analyst para aislar el endpoint y profundizar en conexiones de red asociadas para verificar persistencia, a la vez realizar hunting de IP relacionada a ejecutable malicioso.
